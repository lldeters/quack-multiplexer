  kubectl -n {{ $ns }} rollout status deployment/{{ $fullname }}

Clients in the cluster (plain HTTP unless server.tls is set):

  CREATE SECRET (TYPE quack, TOKEN '<token>', SCOPE 'quack:{{ $fullname }}.{{ $ns }}.svc.cluster.local:9494');
  ATTACH 'quack:{{ $fullname }}.{{ $ns }}.svc.cluster.local:9494' AS lake (DISABLE_SSL true);

From your machine: kubectl -n {{ $ns }} port-forward svc/{{ $fullname }} 9494:9494 9495:9495
and ATTACH 'quack:localhost:9494'.

Admin API token:

  kubectl -n {{ $ns }} get secret {{ include "quackmux.adminTokenSecret" . }} -o jsonpath='{.data.token}' | base64 -d
